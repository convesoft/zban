Implements `DES-AGENT-GUIDE` and the `prime` command.

## Done when

- [x] `VER-AGENT-GUIDE` passes for `zban prime`

## Summary of Changes

- New core module `guide` (`DES-AGENT-GUIDE`): the guide is one template, `src/guide.md`, compiled in with `include_str!`. Its type, status, priority and readiness-reason lists are `{{...}}` slots filled from `IssueType::ALL`, `Status::ALL`, `Priority::ALL` and the `Display` of `NotReady`, so they cannot disagree with the binary (`REQ-AGENT-GUIDE`). It has 107 lines and the sections of `DES-AGENT-GUIDE` except the handoff section, which zb-qkj8tj adds together with `--handoff`.
- New operation `operations::guide(directory)` (`DES-SHARED-CORE`) returns `Guide { guide: Option<String> }`: the guide when a project is found from `directory`, `None` otherwise. A project whose `config.toml` is invalid still counts as found, because the guide does not depend on it; `DES-AGENT-GUIDE` now records this. Other errors, such as a missing `-C` directory, fail as usual.
- New `prime` command: a thin `Command::Prime` variant in `src/cli.rs` that prints the guide, or nothing outside a project, and `{"guide": ...}` or `{"guide": null}` with `--json`. Exit status is 0 in both cases.
- The template names operations as `zban ...` code spans, so the MCP rendering (zb-bbyjed) can map each span to its tool. No MCP rendering is added here, because the tool argument names are not fixed until the server exists. Rejected: building the reference from clap's command definitions: the core library would then depend on the CLI adapter, and clap lists every option rather than the main ones.
- After rebasing onto zb-yj8xta, the guide names `zban check [--fix]` in the reference and tells agents to run `check` after fixing a broken issue file. Before that change, `guide_lists_every_command_agents_use` failed with "the reference lists no `zban check`", as intended. Added a note to zb-hqez4b to update the guide's `--fix` line when `--fix` starts removing temporary files.
- Docs: the agents page, the command-line page and the README now say that `prime` works.
- Tests: `tests/prime.rs` adds 8 tests for `VER-AGENT-GUIDE` through the binary. They cover a snapshot of `zban prime` (`tests/snapshots/prime.md`, refreshed with `ZBAN_UPDATE_SNAPSHOTS=1`) from the root and from a subdirectory, `--json`, empty output and `{"guide": null}` outside a project, `-C <project>` from outside, an invalid configuration, a missing `-C` directory, and vocabulary lists equal to the code enumerations. They also check that every `zban` command and option named in the guide appears in that command's `--help`, with valid example values; that the reference lists every command except `init`, `prime` and `mcp`; and that the guide has its sections and stays at 150 lines or fewer. A unit test checks that every template slot is filled. Breaking the template on purpose confirmed that the tests catch a made-up option, an invalid status value, an unknown command and a dropped reference entry.
